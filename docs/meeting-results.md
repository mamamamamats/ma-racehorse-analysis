# 週末の結果集計と日別集計

「今週の結果」は月〜日の暦週ではなく土・日・開催が登録されている直後の月曜をまとめる。2026/11/23（月）は11/21・22側、11/28・29とは別集計。11/30（月）の開催が登録されていれば11/28・29・30をまとめる。火〜金の開催を次の週末へ混ぜない。週の計算と「今週のレース」の日付は日本時間で判定。開催のある月曜当日は直前の土日と一緒に表示し、月曜開催がなければ次の週末を表示する。

編集モード「今週のレース」で日付を開くと、「この日の予想結果・回収率を見る」を開ける。過去開催と共通の保存済み予想・着順・払戻・フォーメーション集計・SNS用画像を、その日付だけで表示。開いた間は日別集計を表示し、閉じると下の週間集計へ戻る。週間と日別の重複ID・設定操作の競合を避けるため、同時には描画しない。予想の順位や払戻の式は変更しない。

日別の取得済みデータをメモリで保持し、週・日付の切り替えは使い回す。「結果を再取得」または明示的な保存後にだけ破棄する。非同期取得中に日付を変えても、前の日付の結果で表示を上書きしない。

公開結果カードの期間も同じ週末で保存する。月曜開催がある場合でも、掲載期限は従来どおり次の週末後の月曜00:00（日本時間）。以前公開したカードは保存済み集計なので自動で書き換えない。修正後の集計を公開する場合は編集画面の「この週の結果をユーザー画面へ更新」を押す。
