# 予想精度・実績／レース研究の整理（2026-11-17）

一般モードのタブ順は「ホーム → 予想アシスト → 予想精度・実績 → レース研究 → 全頭診断」。内部のview IDは既存のままで、保存済みリンクや採点には影響しない。

## 予想精度・実績

サブ画面を「予想実績・スコア検証」「好走馬の特徴」「保存済み予想」に分ける。

- 実績：対象レース数、本命1着率・3着内率。印別平均着順とBOX回収率は折りたたみ内。スコア帯別、順位別、1位2位点差別の3着内率グラフを配置。
- 好走馬の特徴：実際の3着以内の馬の保存時平均スコア・6軸プロファイル・基礎点/適性加点・平均最終角位置。回顧Fは平均から除外。不明は0として補完しない。
- 保存済み予想：当時保存した順位と点数の詳細。現時点の評価では再計算しない。

採点モデル（現行6項目／旧5項目）、馬場、重み・詳細設定、競馬場、コース、距離、クラス、開催日の期間、保存タイミングを独立して選択する。初期値は現行モデル、全馬場、全重み。期間・競馬場・クラス・重みなどは詳細条件の折りたたみ内に置く。モデルの違う点数は平均・グラフで混ぜない。モデルを変えても馬場等のフィルターは維持する（モデル内に存在しない競馬場等は解除）。

開催日以前の保存が初期値。同日保存は発走前か未確認と明記。翌日以降の登録・日付不明は別扱いとし、利用者がタイミングの選択を変更できる。実績・好走プロファイルは同じ選択対象を使う。

同一モデル・レースに複数の設定がある場合は、開催設定の馬場に一致する予想を優先し、最初の保存を採用する。実際の設定に一致する記録がない場合も、選択モデルの既存保存を使う（従来の共通標準予想限定とは異なる）。重みを固定したい場合は設定選択で絞る。未照合・結果一部・重複の件数を明示する。

好走プロファイルは従来のmeta/publicConditionTraitsに固定公開された40Rだけでなく、予想・結果JSON＋差分から集計する。位置取り・F確認には既存の軽量positionRecordsと差分を使用する。全馬のFirestore読み込みは追加しない。一般モードでDB書き込みは行わない。

## レース研究

回顧に基づくペース、ラップ構成、上位馬の枠、不利の分類、対象レースと過去ラップの比較、前半と後半の速さ、回顧本文を置く。好走馬の保存時スコアのプロファイルは置かない。レースそのものの特徴と、予想の実績を分ける。

## 編集モード・互換性

分析画面でも採点モデルごとの馬場合算を初期表示とし、条件別表は競馬場×コース×距離を初期単位にする。馬場別の表は選択肢として残す。旧来の標準登録・各レースの馬場選択・保存済みスコア・SNS週間結果の保存仕様は変更しない。

公開用好走集計を保存する既存ボタンはモデルを区別した集計を保存する。一般画面のプロファイルはこの手動更新に依存しない。週間SNSカードは従来の明示公開と掲載期限を維持し、好走プロファイル画面では混在させない。
