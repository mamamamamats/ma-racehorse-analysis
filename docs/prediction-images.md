# 編集モードのSNS用予想画像

編集モードで、今週のレースまたは過去開催の「AIアシスタント予想」を開き、「今回の予想」の横にある「予想画像を開く」を押す。プレビューからPNG保存または端末のファイル共有を使える。ユーザーモードには保存ボタンを出さない。

画像には開催日・競馬場・R・レース名、馬場と予想設定、表示中の全印（☆を含む）・馬名・総合スコア・根拠を掲載する。その下に、今回の比較条件とクラス、想定ラップ型、分類済みレース数・平均ラップの件数、前傾／後傾／平均型の内訳、前後半の平均タイムを掲載。最後に印外の紐候補を小さく表示する。材料不足なら想定を捏造せず「判断材料不足」とし、未取得の平均タイムは表示しない。

幅1080px、内容に応じて高さを伸ばすPNG。日本語の長文・数字を折り返し、根拠や候補を切り捨てない。端末がファイル共有に対応しない場合はPNGダウンロードへ切り替える。共有キャンセル時はダウンロードを始めない。

## 採点・保存との関係

表示された予想をレンダリング時にコピーして画像化する。画像を開いた後で別レースを計算しても、開いている画像のレース・印・スコアは差し替わらない。新しい馬場・重みの予想を共有する場合は、予想を再表示して画像を開き直す。

採点エンジン、印選定、標準予想登録、過去の予想スナップショットは変更しない。画像の点数は画面の `originalScore` であり、印調整用の `selectionScore` に置き換えない。画像保存・共有の処理はFirestoreやDataArchiveを呼ばず、追加のDB読み取り・書き込みを行わない。予想の登録とは別の操作。

検証：`node --test tests/*.test.mjs`（218件）、`node tests/browser/prediction-share.cjs`、`node tests/browser/pace-selection.cjs`。ブラウザ検証は外部通信を遮断して実行。実際のユーザーモードのランキング入口と編集モードの予想登録入口を使い、良・稍重・重・不良、標準／カスタム重み、比較クラスを変えた5条件で全馬の点数と印の一致を確認。追加で編集画面の実際のAIアシスタント上での表示位置、PNGの生成・ダウンロード、共有、別レースへの切り替え時の画像保持、ユーザー画面にボタンがないことを確認した。

ラップ欄は、前傾・後傾・平均型の件数と割合を色分けバーで表示し、同条件の平均区間ラップを折れ線で表示する。折れ線は200m換算・上ほど速い軸で、距離の半分に破線を付ける。100m区間等は実区間距離で200m換算する。描画用の元区間データがない場合はグラフを作らず未取得と表示する。既に計算済みの平均値を図にするだけで、採点・印選定・DBアクセスは追加しない。

各馬の点数は基礎点と適性加点の積み上げ棒グラフでも表示する。画像と予想アシストの表示上限は10・15・20点の3段階。重みに基づく理論上限（6＋0.7×競馬場・距離・馬場の重みの合計）に最も近い5点刻みを選び、10〜20点に収める。標準重み3は10点、3項目すべて4は15点、すべて6は20点となる。レースのメンバーや最高点では変えない。表示上限を超える棒は最大幅で止めるが、実際の点数・採点・印は変更しない。画像を開いた際の表示上限もコピーして保持する。内訳のない過去データは総合点のみ灰色で表示する。

予想画像と編集予想欄の上部に評価済み頭数／出走頭数を表示する。今回のスコアが有限値の馬を評価済みとして数え、8割以下なら注意書きを表示する。0頭のレースでは割合警告を出さない。ユーザーモードも上部の頭数表示直後に同じ基準の注意書きを出す。

## 日付別の本命一覧

編集モードの開催日ごとの操作欄「この日の本命一覧画像」からPNG保存・共有する。標準予想登録と同じ対象クラス（新馬・未勝利を除く）を開催場別・R順に並べ、共通エンジンの標準重み・各レース設定の馬場で得た◎を掲載する。評価不足で◎がないレースも残し、評価済み8割以下には注記する。登録済みカスタム予想を抜き出す機能ではなく、現在のデータによる標準予想。過去日も当時の再現ではない。

既に読み込まれた共通回顧を再利用し、未読み込みなら公開JSONのbaselineのみを読む。Firestoreへのフォールバック、予想登録、結果照合は行わない。公開JSONを取得できない場合はエラー表示で停止する。全レースを1枚に収め、高さは行数に応じて伸ばす。日別一覧でも既存のPNG保存・ファイル共有の仕組みを使う。
